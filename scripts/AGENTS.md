# 各スクリプトについて

- accounts.sh: GitHubアカウントの管理とSSHキーの生成を行います。
- symlink.sh: dotfilesのシンボリックリンクを作成します。
- install.sh: Nixのインストールと、必要なセットアップを対話的に行います。
